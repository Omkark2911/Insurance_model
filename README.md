# Insurance_model
This project focuses on applying Linear Regression to an Insurance dataset to understand the relationship between different customer attributes and their insurance charges.

The model is trained using selected independent variables and its performance is evaluated using:

R² Score (R-Squared)
Adjusted R² Score

The main objective is to build a regression model that can predict insurance charges and determine how well the independent variables explain the variation in the target variable.


Import the required libraries
Load the Insurance dataset
Perform basic data exploration
Check for missing values
Perform data preprocessing
Convert categorical variables into numerical form
Select independent and dependent variables
Split the dataset into training and testing sets
Train the Linear Regression model
Make predictions on the test dataset
Evaluate the model using R² Score
Evaluate the model using Adjusted R² Score
Analyze the model performance
